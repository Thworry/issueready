# Changelog

All notable changes to IssueReady are documented in this file.

## [Unreleased]

## 0.1.1 - 2026-08-26

### Changed

- Positioned IssueReady more clearly as a maintainer-side pre-publish, triage, and contributor-onboarding check, with direct links to the live site and an explicit boundary from RepoScope.
- Made the complete desktop and mobile Playwright matrix portable across contributor machines, CI, and Pages deployment.
- Updated compatible development dependencies after individual review and fresh CI validation.
- Replaced the vulnerable `@lhci/cli` development dependency chain with current direct Lighthouse tooling while preserving three runs and every `0.95` score threshold.

## 0.1.0 - 2026-08-11

### Added

- First bilingual, read-only, browser-local checks for the quality and freshness of beginner-labelled GitHub issues.
